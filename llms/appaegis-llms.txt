# Appaegis (Mammoth Cyber)

> Appaegis, now Mammoth Cyber, is an enterprise zero-trust access and secure Enterprise AI Browser company. Its API-first platform exposes a REST (v1 + v2) and GraphQL management API on api.mammothcyber.net for administering users, teams, access roles, policies, applications, networks, registered devices, blocked-site lists, and URL categories. Authentication is a token exchange: POST an apiKey/apiSecret pair to /api/v2/authentication for an idToken, then present it (idToken header for REST, Authorization: Bearer for GraphQL).

## APIs

- [Mammoth Cyber Management API (samples + README)](https://github.com/appaegis/api-script-samples): First-party Python examples and the documented v1/v2 REST + GraphQL surface. Base URL https://api.mammothcyber.net.
